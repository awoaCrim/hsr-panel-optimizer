## 关键机制澄清（修正 v1.5 模型）

1. **迷迷强化行动不是伤害**：充能满后迷迷行动变为"我会！帮你！"——100% 拉条一名队友并给【声援】。
   声援期间该队友**每段伤害**（含击破/DoT）附加一次真伤 = 该段伤害 × 真伤比例。
   真伤不削韧、不算行动、不吃防御/抗性（独立乘区）。
2. **真伤不是光环**：不是"迷迷在场全队 +10%"，而是**声援目标独享**的 per-hit 附加。
3. **普攻是多段随机单体**：4 段各自随机选目标（每段独立判定），随后一次全体伤害。
4. 迷迷继承忆师攻击力（技能描述 "of Mem's ATK"；Mem 面板 = 忆师属性继承，比例待实测确认）。
