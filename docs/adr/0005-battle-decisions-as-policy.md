# 0005 战斗决策纳入优化对象（策略字段化 + 程序搜索）

写死的行动序列（rotation v2）让面板优化基于次优打法：同一面板下，策略差异（SP 分配给谁、红A 连打几次、辅助是否开大）可带来 2 倍以上伤害差（实测基线策略 27.8 万 vs 程序搜索最优 96.4 万）。决定把战斗决策建模为**策略（policy）**：每个角色一组决策规则（大招开关/连打上限/战技预算/拉条目标），模拟器按规则实时决策；**策略搜索**器在当前面板下枚举参数空间求最优策略，LLM 迭代每轮获得程序最优策略作为参考。

理由：
- 决策是真实优化空间（实测 +247%），写死序列会系统性低估面板的真实上限
- 策略字段化让 LLM 可输出、程序可验证；搜索保证"面板基于最优打法验证"的确定性
- 序列模式（v2 actions）保留兼容，逐步迁移

被否方案：LLM 直接输出完整决策树（每行动时刻 if-then 规则）——表达力强但易错、难验证；全自动搜索+LLM 只管面板——用户要求 LLM 保留策略决策参与（选型 1+2 混合）。
