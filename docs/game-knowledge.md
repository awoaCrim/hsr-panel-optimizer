# 星穹铁道 AI 面板优化 · 游戏信息大纲

> **v2 定位（ADR-0007）**：本文档是**面板优化应用**（上层应用之一）的知识包。项目主形态为**战斗推演模拟引擎**——LLM 逐步指挥战斗（决策空间对齐官方规则：主动行动 + 大招时机），其知识包（机制规则 + observe/act 决策契约 + 回退/分支语义）将在 P1 随 LLM 指挥接口实现补充。
> 本文档是"AI 计算全队最佳面板属性"的知识包大纲。工作模式：**LLM 提出面板方案 → 程序用精确公式验证 → 多轮迭代收敛**。
> 配套文档：`data-schema.md`（数据字段清单与数据源映射）。
> 状态：v1 草案（数据字段以 StarRailRes 与 TurnBasedGameData 实测结构为准）。

## 一、AI 工作流程契约

### 1.1 输入（用户提供）

| 输入项 | 内容 |
|---|---|
| 队伍 | 4 名角色 + 定位（主C/副C/辅助/生存） |
| 装备池 | 可用光锥（含叠影）、遗器套装池、副词条预算（词条数） |
| 环境 | 目标关卡（如混沌回忆第 N 层）、敌人配置、场地 buff |
| 优化目标 | 默认"最大期望伤害 + 满足指定轮次约束（0T/2T/4T）"，可切换为"纯最大伤害"或"特定配速要求" |

### 1.2 LLM 输出（面板方案 JSON）

```json
{
  "team": {
    "role_1_id": "1204",
    "speed_order": ["1204", "1308", "1107", "1211"]
  },
  "builds": {
    "1204": {
      "light_cone": {"id": "23012", "superimposition": 1},
      "relic_set": ["101", "101", "101", "101", "107", "107"],
      "main_stats": {"body": "crit_dmg", "feet": "speed", "sphere": "fire_dmg", "rope": "atk"},
      "substat_target": {"crit_rate": 70, "crit_dmg": 140, "speed": 134, "atk": 2800, "break_effect": 200},
      "energy_recharge": 1.0
    }
  },
  "rotation": {"1204": ["E", "EB", "B", "ULT", "E"], "sp_balance": 0}
}
```

### 1.3 程序验证（5 个验证器）

| 验证器 | 输出 |
|---|---|
| 伤害期望计算器 | 每轮期望伤害、循环总期望、DPS |
| 速度轴模拟器 | 行动序列、各角色行动次数、首轮/后续轮次行动值 |
| 能量循环验证器 | 大招频率、卡能量位置、所需充能断点 |
| SP 循环验证器 | SP 随时间曲线、断点（SP 为负的位置） |
| 约束检查器 | 目标轮次是否达成、未达标约束清单 |

### 1.4 迭代协议

1. 首轮：LLM 输出完整方案 → 程序验证 → 返回结果
2. 迭代：LLM 依据验证结果（如"速度 132 差 2 点未达 134 断点""SP 第 3 回合见底"）调整方案，最多 **5 轮**（默认）
3. 收敛：输出最终面板 + 配速顺序 + 循环说明 + 替代方案（如"降 1 速词条换 4 暴击词条"）

## 二、游戏机制知识层（AI 的"规则书"）

### 2.1 属性体系

**基础属性（8 项）**
| 属性 | 说明 | 词条基准 |
|---|---|---|
| HP / 攻击 / 防御 | 数值属性，随等级成长 | 攻击 4.32% 词条 |
| 速度 | 决定行动值，1 点速度影响整体行动频率 | 2.4 速度/词条 |
| 暴击率 / 暴击伤害 | 期望乘区 | 3.24% / 6.48% 每词条 |
| 效果命中 / 效果抵抗 | 异常状态相关 | 4.32% / 4.32% |

**进阶属性**：击破特攻（6.48%/词条）、能量回复效率（3.24%/词条）、治疗加成、属性伤害加成（4.32%/词条）。

### 2.2 伤害公式（完整乘区）

```
最终伤害 = 技能倍率 × 攻击力 × 增伤乘区 × 暴击期望 × 防御乘区 × 抗性乘区 × 易伤乘区 × 削韧/破盾修正
```

- **暴击期望** = 1 + 暴击率 × 暴击伤害（暴击率 ≤ 100%，超出部分无效）
- **防御乘区** = 200 / (200 + 敌人防御力)（同等级敌人防御 ≈ 等级相关固定值，取 800～1200 区间，需按关卡等级查 HardLevelGroup）
- **抗性乘区**：敌人对应属性抗性（默认 20%），弱点不改变抗性但允许削韧
- **增伤乘区**：属性伤害加成 + 全伤加成 + 技能类型加成 + 光锥/遗器增伤（加法叠加）
- **易伤乘区**：独立乘区（乘法叠加）
- **击破伤害** = 等级系数 × 属性倍率 × 击破特攻加成（击破特攻 100% 时伤害翻倍）；击破瞬间对敌人造成行动延后 25%

### 2.3 行动值 / 轮次系统（排轴核心）

- **行动值（AV）= 10000 / 速度**；行动条按 AV 推进，先到先行动
- **轮次**：混沌回忆每轮 150 AV；第 1 轮 150，之后每轮 +100（记忆宫殿规则：首轮 150，次轮起 100）。**速度断点**：150/1 回合=首轮行动值需求，常见阈值 134（首轮 2 动+次轮 1 动）、141（首轮 2 动）、145、160（次轮 2 动）
- **行动延时**：技能自带的 DelayRatio（行动后按比例推后）
- **拉条/推条**：减少/增加目标剩余行动距离的百分比（布洛妮娅战技 30% 拉条、流萤大招 24% 等）
- **速度变化**：战斗中速度临时变化（如流萤大招后速度 -60），需分段计算行动值
- 开局：全体按初始速度排入行动条；终结技不占行动条

### 2.4 能量 / 充能机制

- **大招费用档位**：80 / 90 / 100 / 110 / 120（角色 ult_cost，见 characters.csv 或 StarRailRes）
- **回能规则**：
  - 行动回能：普攻 20、战技 30、终结技 5（释放后）；部分角色有额外回能（技能 ParamList 中）
  - 受击回能：按敌人攻击档位 5/10/15/20
  - 击杀回能：10；部分光锥/命座提供击杀回能
  - 充能效率：能量回复效率 × 所有回能
- **充能断点计算法**：给定循环（如 EEA），所需充能效率 = 大招费用 / 循环总回能；输出"还需多少充能可缩短 1 回合"（参考 HSR-Optimal-Rotation-Calculator 的 print_er_breakpoint）

### 2.5 战技点（SP）机制

- 上限 5 点、开局 4 点
- 普攻 +1、战技 -1（特殊角色如饮月 -3，见 SPMultipleRatio/BPNeed）
- **全队 SP 循环约束**：任意前缀的行动序列 SP 非负；循环结束时 SP 不低于开局（可持续性）
- 布洛妮娅/花火等辅助的 SP 经济是配速与面板权衡的核心

### 2.6 韧性 / 击破机制

- 敌人韧性条：弱点属性攻击可削韧（削韧值见技能 StanceDamageDisplay）
- 击破：韧性归零 → 行动延后 25% + 击破伤害 + 击破效果（减速/风化/纠缠等）
- 韧性未破时受到伤害降低（比例按敌人类型）

### 2.7 遗器 / 词条价值体系

- **主词条**：衣（暴击率/暴伤/攻击/治疗）、鞋（速度/攻击）、球（属性伤害/攻击）、绳（充能效率/击破特攻/攻击）
- **副词条池**：HP/攻击/防御（数值+百分比）、速度、暴击率、暴击伤害、效果命中、效果抵抗、击破特攻
- **词条数值表**（每词条）：暴击率 3.24%、暴伤 6.48%、攻击 4.32%、速度 2.4、击破 6.48%、充能 3.24%（按 5 星遗器副词条均值）
- **主词条数值**（5 星满级）：暴击 32.4%、暴伤 64.8%、攻击 43.2%、速度 25、充能 19.4%、击破 64.8%、属性伤 38.8%
- **词条预算**（已实现）：每人 ≤ 30 有效副词条；程序按 `白值 + 光锥 + 主词条 + 副词条` 装配面板并审计预算（build.py），LLM 只分配词条、无法输出作弊面板
- **套装效果**：2 件套/4 件套（如 2+2 或 4 件套，按角色选择）
- 面板收益评估：攻击稀释、双暴收益曲线、速度断点收益阶跃
